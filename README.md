## 📁 파일 구조

```
sound-experiment/
│
├── index.html        # 메인 페이지 (수정 불필요)
├── style.css         # 디자인 스타일 (수정 불필요)
├── app.js            # 실험 진행 로직 (수정 불필요)
├── sounds.js         # ★ 음원 목록 설정 파일 (여기만 수정)
│
└── audio/            # ★ 음원 파일 폴더 (여기에 파일 넣기)
    ├── A01.mp3
    ├── A02.mp3
    ├── A03.mp3
    │   ...
    └── A24.mp3
```

---

## 🎵 음원 파일 넣는 방법

1. `audio/` 폴더를 만들고, 24개의 음원 파일을 넣습니다.
2. 기본 파일명 형식: `A01.mp3` ~ `A24.mp3`
3. MP3, WAV, OGG, AAC 모두 사용 가능합니다.

### 파일명을 바꾸고 싶다면?

`sounds.js` 파일의 각 항목에서 `file` 값을 수정하세요.

```js
{ id: 1, label: "A01", type: "effect", file: "audio/A01.mp3" },
//                                             ↑ 이 부분을 원하는 파일명으로 변경
```

---

## 🔧 음원 순서·종류 변경 방법

`sounds.js` 파일의 `SOUND_LIST` 배열을 수정하면 됩니다.

| 항목 | 설명 | 값 |
|------|------|-----|
| `id` | 음원 순번 | 1 ~ 24 |
| `label` | 화면에 표시할 이름 | `"A01"` 등 자유 |
| `type` | 음원 종류 | `"effect"` (단순 효과음) / `"ambient"` (추상적 배경음) |
| `file` | 오디오 파일 경로 | `"audio/파일명.mp3"` |

### 재생 시간 변경

```js
const PLAY_DURATION = 60;        // 각 음원 재생 시간 (초)
const TRANSITION_DURATION = 10;  // 전환 화면 대기 시간 (초)
```

## ▶️ 실행 방법

### 로컬에서 실행할 때 (권장)

브라우저 자동재생 정책 때문에 파일을 직접 더블클릭하면 오디오가 재생되지 않을 수 있습니다.  
간단한 로컬 서버를 통해 실행하세요.

**방법 1 — Python (설치 불필요)**
```bash
cd sound-experiment
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

**방법 2 — Node.js**
```bash
npx serve .
```

**방법 3 — VS Code Live Server 확장**  
VS Code에서 `index.html`을 열고 → 우클릭 → "Open with Live Server"

### GitHub Pages로 배포할 때

1. GitHub 저장소에 이 폴더 전체를 올립니다.
2. Settings → Pages → Source: `main` 브랜치 루트 선택
3. 배포된 URL로 접속

## ⚠️ 주의사항
